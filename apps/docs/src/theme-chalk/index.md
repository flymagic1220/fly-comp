# 基本情况

本主题样式库提供了统一的 UI 样式规范和变量定义。

## 核心功能

- 提供统一的设计 token（颜色、字体、间距等）
- 基于 CSS Variables 实现，支持动态主题切换
- 与 Element Plus 设计语言保持一致

## 版本要求

- **Vue**: ^3.0.0
- **Element Plus**: ^2.x

## 访问域名

```ts
import '@fly/theme-chalk/dist/index.css';
```
