# 基本情况

本配置包为所有项目提供统一的 StyleLint 规则配置，确保代码风格一致性。

## 核心功能

- 提供 StyleLint 规范配置
- 支持 SCSS/Less/CSS 检查
- 统一代码风格

## 版本要求

- [StyleLint](https://stylelint.io/) >= 15.x
