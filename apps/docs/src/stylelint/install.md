# 安装

## 使用包管理器

::::code-group

```shell [pnpm]
pnpm add @fly/stylelint-config --save-dev
```

```shell [npm]
npm install @fly/stylelint-config --save-dev
```

```shell [yarn]
yarn add @fly/stylelint-config --save-dev
```

## 安装其它依赖

此配置文件仅仅提供了 stylelint 的配置，还需要项目中安装 stylelint 的运行时依赖：

- [stylelint](https://stylelint.io/)
